# Maintaining Kindr SEO

Each root HTML file owns its page metadata (for example index.html and donate-medical.html). Edit the head of these files, not dist: dist is regenerated by the build.

When the page's purpose or content changes:
1. Update its title with a clear topic and Kindr branding.
2. Update the description with an accurate, unique summary, typically one or two concise sentences.
3. Keep og:title and twitter:title aligned with the title; keep og:description and twitter:description aligned with the description.
4. Keep noindex on account, password, checkout and campaign creation pages. This is not access control; private information still requires backend authentication.
5. Run npm run build and publish through your normal deployment process. Use View Page Source to check the published tags.

Campaign metadata updates in public/campaign.js from the campaign title and story/description. Social crawlers may not execute this JavaScript. For reliable campaign sharing previews and initial HTML metadata, render each campaign's metadata on the server or prerender public campaign URLs.

Before launch:
- Confirm the production domain and preferred URL format, then add absolute canonical URLs, og:url and a public sharing image.
- Generate a sitemap for public pages and valid public campaign URLs; keep each campaign ID distinct and exclude account and checkout URLs.
- Verify robots.txt and hosting headers allow crawling public pages and assets.
- Verify the domain in Google Search Console, submit the sitemap and inspect representative URLs.
- Use server rendering or prerendering for important React content where practical; verify rendered content in Search Console.

Review monthly and after substantive content changes: Search Console indexing and search queries, broken links, mobile usability, page speed, useful headings and descriptive image alt text. Avoid changing tags simply to keep them fresh. Rankings and Google's displayed snippets are not guaranteed.

Reference: https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics
